# 🏓 Pong Game

A classic **Pong Game** built using **Python** and the **Turtle** graphics library. This project recreates the iconic arcade game where two players compete by controlling paddles and preventing the ball from passing their side of the screen.

## 🚀 Features

* Two-player gameplay
* Smooth paddle movement
* Ball collision detection
* Score tracking
* Increasing game speed after paddle hits
* Simple and interactive graphical interface using Turtle

## 🛠️ Technologies Used

* Python 3
* Turtle Graphics Library

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/pong-game.git
   ```

2. Navigate to the project folder:

   ```bash
   cd pong-game
   ```

3. Run the game:

   ```bash
   python main.py
   ```

> Make sure Python 3 is installed. The Turtle library comes pre-installed with the standard Python distribution.

## 🎮 Controls

| Player       | Keys                     |
| ------------ | ------------------------ |
| Left Paddle  | **W** (Up), **S** (Down) |
| Right Paddle | **↑** (Up), **↓** (Down) |
